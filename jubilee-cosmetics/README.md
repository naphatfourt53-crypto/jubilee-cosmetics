# Jubilee Cosmetics - เว็บอีคอมเมิร์ซเครื่องสำอาง

เว็บร้านค้าอีคอมเมิร์ซร้านเครื่องสำอางและเครื่องประดับพรีเมียม ออกแบบโดยได้แรงบันดาลใจจาก Jubilee Diamond, Dior, Mercelo และ Swarovski

## ✨ ฟีเจอร์ที่สร้างไว้ทั้งหมด

### หน้าหลักสำหรับลูกค้า
| ไฟล์ | รายละเอียด |
|------|-------------|
| `index.html` | หน้าแรก — Hero แบนเนอร์, หมวดหมู่ยอดนิยม, สินค้าแนะนำ, โปรโมชันสมาชิก, เหตุผลที่ควรเลือกซื้อ, ฟอร์มสมัครรับข่าวสาร |
| `products.html` | หน้าสินค้าทั้งหมด — กรองตามหมวดหมู่, เรียงราคา, ค้นหาสินค้า |
| `product-detail.html` | รายละเอียดสินค้า — รูปหลัก + ภาพย่อ, ราคาปกติ/ลด, ปุ่มใส่ตะกร้า |
| `cart.html` | ตะกร้าสินค้า — ปรับจำนวน, ลบสินค้า, คำนวณยอดรวม ค่าจัดส่ง |
| `checkout.html` | หน้าชำระเงิน — กรอกข้อมูลจัดส่ง, เลือกวิธีชำระ (PromptPay/บัตร/COD), ยืนยันคำสั่งซื้อ |
| `pages/about.html` | เกี่ยวกับเรา |
| `pages/contact.html` | ติดต่อเรา — ข้อมูลร้าน, ฟอร์มส่งข้อความ |

### หน้าผู้ดูแลระบบ (Admin)
| ไฟล์ | รายละเอียด |
|------|-------------|
| `admin.html` | แผงควบคุมผู้ดูแล — ภาพรวมสถิติ, จัดการสินค้า (เพิ่ม/ลบ), ดูคำสั่งซื้อ, จัดการลูกค้า, ตั้งค่าร้าน |

### ระบบ backend จำลอง (ใช้ localStorage แทนฐานข้อมูลจริง)
เนื่องจากสร้างบนเครื่อง locaux ไม่สามารถติดตั้งเซิร์ฟเวอร์จริงได้ จึงสร้าง **ระบบจำลองฐานข้อมูล** ที่เก็บข้อมูลใน browser localStorage:
- สินค้า, คำสั่งซื้อ, ข้อมูลลูกค้า ถูกบันทึกลง localStorage
- หน้าแอดมินสามารถเพิ่มสินค้าใหม่และดูคำสั่งซื้อได้จริง
- เมื่อเปลี่ยนเครื่องหรือล้าง cache ข้อมูลจะหาย (สำหรับระบบจริงต้องต่อกับเซิร์ฟเวอร์ + ฐานข้อมูลจริง)

### ระบบชำระเงินจำลอง
หน้า `checkout.com` จำลองขั้นตอนการชำระเงินจริง:
1. กรอกข้อมูลการจัดส่ง (ชื่อ, อีเมล, โทร, ที่อยู่)
2. เลือกวิธีชำระเงิน (PromptPay, บัตรเครดิต, เก็บเงินปลายทาง)
3. ตรวจสอบรายการสั่งซื้อ
4. ยืนยันการสั่งซื้อ → แสดงหน้าสำเร็จพร้อมเลขคำสั่งซื้อ

## ⚠️ สิ่งที่ยังขาดเพื่อเปิดรับลูกค้าจริง

เพื่อให้เว็บนี้ **สมบูรณ์และเปิดขายจริง** คุณต้องพัฒนาต่อดังนี้:

1. **เซิร์ฟเวอร์และฐานข้อมูลจริง** (Node.js/PHP/Python + MySQL/PostgreSQL)
   - ปัจจุบันใช้ localStorage ซึ่งอยู่เฉพาะเครื่องนั้น
   - ต้องสร้าง API สำหรับสินค้า, คำสั่งซื้อ, ผู้ใช้

2. **ระบบสมาชิกและล็อกอินจริง**
   - สมัครสมาชิก, เข้าสู่ระบบ, ประวัติคำสั่งซื้อ

3. **ระบบชำระเงินจริง (Payment Gateway)**
   - ต่อกับ Stripe, PayPal, Omise, Paysbuy หรือธนาคารในไทย
   - รองรับ PromptPay QR, บัตรเครดิต

4. **SSL Certificate (HTTPS)**
   - จำเป็นสำหรับเว็บที่รับชำระเงินและเก็บข้อมูลลูกค้า

5. **รูปภาพสินค้าจริง**
   - ปัจจุบันใช้ไฟล์ placeholder SVG ต้องเปลี่ยนเป็นรูปสินค้าจริง

6. **ระบบสต็อกสินค้า**
   - ตรวจสอบจำนวนสินค้าคงเหลือ, ปิดการสั่งเมื่อสินค้าหมด

7. **การจัดส่งและติดตามพัสดุ**
   - คำนวณค่าจัดส่งตามพื้นที่จริง, เลขพัสดุติดตามสถานะ

8. **ความปลอดภัยและกฎหมาย**
   - นโยบายความเป็นส่วนตัว (PDPA), ข้อกำหนดการใช้บริการ
   - การยืนยันตัวตนและการป้องกันการโจมตี XSS/CSRF

## 🚀 วิธีเปิดดูเว็บ
เนื่องจากเป็นเว็บ static (HTML/CSS/JS) คุณสามารถ:
1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที
2. หรืออัปโหลดไฟล์ทั้งหมดขึ้นโฮสติ้ง (GitHub Pages, Netlify, หรือเว็บโฮสติ้งทั่วไป)

หากต้องการให้ผมช่วยพัฒนาส่วนต่อไป (เช่น ต่อกับฐานข้อมูลจริง, ระบบชำระเงินจริง, หรือหน้าแอดมินขั้นสูง) แจ้งได้เลยครับ!
